# T6 release rehearsal

Live `crapts-v0.1.0-rc.1` rehearsal completed on 2026-11-26 against `main` commit `ff4c96a26d63d3055aaf1e99a4157cc7b1198364`.

## Registry setup and trusted publishing

- **crates.io:** `CARGO_REGISTRY_TOKEN` published `cargo-crap-core 0.2.1` and `crapts 0.1.0-rc.1` under the maintainer's crates.io account, confirming both `publish-new` and `publish-update` grants.
- **npm bootstrap and trust:** All seven npm packages live under the maintainer's `@minikin_` scope (`https://www.npmjs.com/~minikin_`). Each package was bootstrapped at `0.0.0-bootstrap.0` (`--access public --tag bootstrap`) and linked to GitHub Actions workflow `release-crapts.yml` in `minikin/cargo-crap` with `permissions: publish, stage publish`.
- **OIDC permission check:** Initial `publish-npm` attempts returned `403 Forbidden - OIDC permission denied for this action` because newly created npm trusted publishers defaulted to `stage publish` only. Replacing all seven trust entries via `npm trust github ... --allow-publish` cleared the failure, and `publish-npm` published all seven packages with Sigstore provenance in 53s. The npm trusted-publisher schema exposes only `publish` (`createPackage`) and `stage publish` (`createStagedPackage`), with no separate `dist-tag` toggle. Because `promote-npm` is skipped on pre-releases, `npm dist-tag add` over OIDC runs for the first time on `crapts-v0.1.0`. If npm rejects `dist-tag add` over OIDC, the fallback is running `npm dist-tag add "$pkg@0.1.0" latest` locally for all seven packages.
- **CDN propagation wait:** `npm-smoke` initially hit `E404` during npm CDN propagation because `scripts/release/smoke.mjs` retried for 9 seconds total. Rerunning the failed smoke jobs passed without code changes. The `0.1.0` release update extends `waitForPackage` to 12 attempts (up to 135s).
