## Part 2 — Generic review (code-review skill, medium)

No findings. Two consequences of the spec's design, noted, not defects:

- With `fail-regression = true`, changing `try-weight` alone rescores
  functions and can turn a run red; the stderr warning is what explains it.
  The spec's promise — the mismatch itself does not change the exit code —
  holds.
- The delta envelope records only the current run's `try_weight`, so a
  machine consumer of delta JSON sees the mismatch only on stderr. Outside
  T5's scope.
