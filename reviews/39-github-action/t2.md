Reviewed T2: comparing a pull request with its base commit in the same job.

Spec conformance: _A pull request is compared with its base commit_, _A pull request without regressions passes_, _The base-commit run uses the pull request's config_, _The base-commit run never pays for triage_ and _Extra arguments reach cargo-crap_ each have a job named after them, all green on fc30199, with PR mode on Linux, macOS and Windows.

Found by the first CI run: the workflow runs on its own pull request, so `base` defaulted to this repository's base commit and the push-mode jobs tried to compare against it. They pass an empty `base`.

Fixed in T2:

- The args job could not fail: the loaded baseline is filtered with the current run's excludes, so `— 0 removed` printed either way. It reads the base run's own record.
- Any failure between the two checkouts left the job on the base commit with its configs swapped. A trap restores the pull request's commit, its local edits and an untracked config, and a job with a base that does not compile proves it.
- A forced checkout discarded local edits to tracked files. They are stashed and restored, and the harmless-change job carries one through.
- The config search compared a logical path with git's physical one, so on macOS or Windows it could walk out of the repository and delete a config there. Both sides use physical paths.
- The triage job could not tell a working setup from a broken one: the pull request had no pair to ask about either. The pull request now adds a pair, which the stub must see, and the base's pair must never reach it. A run with a binary built without the `triage` feature failed this check, as it should.
- A branch name or relative `base` is resolved to a commit, after a shallow fetch too. A working directory missing at the base commit skips the comparison with a warning.
- `jq` is gone, so self-hosted runners need nothing new. One JSON run is the gate and the regression count, `regressed` is checked as a count, and a cargo-crap failure (exit 2) is not taken for a gate.
- A failing badge run shows its error instead of dying silent.

Mutants: no `src/` change. The scenario jobs are this spec's acceptance tests.
