## Promotion decisions

`scripts/release/tests/promotions.py` used the workflow's conditions and commands, real preflight outputs, a temporary bare Git remote and a loopback npm dist-tag registry. It checked the wrapper and six platform packages individually and checked both Git refs after every case.

| Case | Fixture result |
| --- | --- |
| Stable 0.1.0 and 1.4.2, all smokes green | All seven npm latest tags and crapts-v1 advanced. |
| 1.4.2-rc.1, all smokes green | Both promotions skipped. |
| Stable 2.0.0, all smokes green | All seven npm latest tags advanced. The prior crapts-v1 target was retained. |
| Failed Action smoke, failed npm smoke, or skipped Action smoke | Both promotions skipped in each case. |
| Stable 0.2.0 followed by stable 0.1.5 | Both promotions advanced to the older line's patch. |
| Push of the moving crapts-v1 ref | The version workflow trigger did not match. |

The root `v1` retained its original target in every case.
